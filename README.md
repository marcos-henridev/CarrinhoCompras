# Project Cart

Aplicação de e-commerce desenvolvida para exibir produtos, adicionar itens ao carrinho e consultar endereços por CEP. Os produtos são carregados pela Fake Store API, enquanto a consulta de endereço utiliza a API ViaCEP.

## Principais tecnologias

- React 18 (para compatibilidade com o Recoil)
- Vite
- JavaScript
- Recoil para gerenciamento de estado
- Emotion Styled para estilização de componentes
- Tailwind CSS
- Fake Store API para o catálogo de produtos
- ViaCEP para consulta de endereços

## Como iniciar o projeto

Antes de começar, tenha o Node.js e o npm instalados na máquina.

1. Instale as dependências:

```bash
npm install
```

2. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

3. Abra no navegador o endereço exibido no terminal. Por padrão, o Vite utiliza:

```text
http://localhost:5173
```

O projeto precisa de conexão com a internet para carregar os produtos e consultar endereços.
